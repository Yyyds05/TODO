|------|-----|

| **语言** | 中文 |

| **UI 框架** | 现有自研组件 + Tailwind CSS |
| **原始需求** | 修复 SkyDesk 致命缺陷（音乐死代码/功能单薄/视图割裂），深化天气-视觉联动，提升渲染质感，补全核心日历功能 |

### 升级后一句话定义

**SkyDesk 是一款天空氛围驱动的日程管理应用——天气实时塑造视觉场景，待办与天象双向共鸣，让每一天的规划都有天空作伴。**

## 4. 需求池

### P0 — 必须做（MVP 补全）

| ID | 需求 | 描述 | 验收标准 |
|----|------|------|----------|
| P0-01 | **音乐系统重构** | 移除 NeteaseCloudMusicApi 依赖，用 Web Audio API 实现 4 种天气环境音效合成（晴/雨/雪/雾） | 删除 MusicService.js 中所有 localhost:3000 引用；4 种音效可独立播放/暂停；天气切换时音频 2s 内交叉淡入淡出；音量可控 |
| P0-02 | **通知提醒** | 支持为事件设置提醒时间，到时触发浏览器 Notification API 推送 | 事件创建时可设提醒（5min/15min/30min/1h/自定义）；到时触发桌面通知；通知点击跳转对应事件；需用户授权后生效 |
| P0-03 | **重复事件** | 支持每日/每周/每月/自定义间隔重复 | 创建事件时可选择重复规则；日历视图中正确展示重复实例；可编辑单次或全部实例；支持设置结束条件（次数/日期） |
| P0-04 | **标签分类** | 支持创建/编辑/删除标签，事件可多标签 | 标签有颜色标识；事件表单可多选标签；侧栏/过滤器按标签筛选；标签管理弹窗增删改 |
| P0-05 | **搜索过滤** | 支持关键词搜索 + 标签/日期/完成状态组合过滤 | 搜索框实时模糊匹配标题/描述；过滤面板支持标签/日期范围/状态组合；结果高亮匹配词 |
| P0-06 | **云朵质感增强** | 在 SkyRenderer 现有贝塞尔云朵基础上，用 Perlin noise 扰动边缘轮廓 | 云朵边缘不再光滑而是自然不规则；不同云朵形态差异明显；帧率不低于 30fps |
| P0-07 | **太阳/月亮质感增强** | 太阳添加体积光（god ray）效果；月亮添加表面纹理暗示 | 太阳有放射状光线且随时间缓动；月亮不再纯白圆盘 |
| P0-08 | **雨/雪/雾质感增强** | 雨添加运动模糊（斜线+拖尾）；雪改为六角形+飘落轨迹；雾添加 Perlin noise 流动 | 雨丝有明显方向和速度感；雪花非圆点有形态；雾气有流动感而非静态色块 |

### P1 — 应该做（体验升级）

| ID | 需求 | 描述 | 验收标准 |
|----|------|------|----------|
| P1-01 | **天气深度联动** | temperature → 色温偏移；humidity → 雾气浓度；windSpeed → 云朵移速/雨丝角度；weatherCode → 音频场景 | 温度 >30°C 偏暖橙、<5°C 偏冷蓝；湿度 >80% 雾气加重；风速 >20km/h 云朵加速、雨丝倾斜 |
| P1-02 | **视图统一 — 天空背景** | CalendarView 和 StatsView 复用 SkyRenderer 渲染背景，替代纯色白底 | 三视图切换时天空场景连贯；日历/统计内容以半透明毛玻璃卡片覆盖在天空中 |
| P1-03 | **视图统一 — 交互语言** | 三个视图统一：浮动添加按钮、右键上下文菜单、拖拽创建/移动事件 | 任意视图可快速创建事件；右键菜单选项一致；拖拽交互模式统一 |
| P1-04 | **键盘快捷键** | N=新建、/=搜索、1/2/3=切换视图、Esc=关闭弹窗、Space=播放/暂停音乐 | 快捷键在任意视图生效；弹窗打开时快捷键正确降级；快捷键提示可查 |
| P1-05 | **事件-视觉双向绑定升级** | 待办密度 → 云量；完成率 → 星星亮度/数量；紧急事件 → 闪电概率 | 有待办时天空不会完全晴朗；完成任务后夜空更璀璨；紧急事件触发偶尔闪电 |
| P1-06 | **日夜自动过渡** | 根据用户本地时间/天气自动切换天空场景（黎明→日间→黄昏→夜晚） | 时间变化时天空色调平滑过渡；日出日落有专门过渡动画 |

### P2 — 可以做（锦上添花）

| ID | 需求 | 描述 | 验收标准 |
|----|------|------|----------|
| P2-01 | **PWA 支持** | 注册 Service Worker、添加 manifest.json，支持安装到桌面 | Lighthouse PWA 审计 >90 分；可离线打开应用（只读模式） |
| P2-02 | **数据导出** | 支持导出事件为 JSON/CSV | 导出文件包含全部事件字段；可按标签/日期范围筛选导出 |
| P2-03 | **Onboarding 引导** | 首次使用时展示 3-4 步交互引导 | 遮罩高亮核心操作区；跳过/完成后不再出现；localStorage 记录完成状态 |
| P2-04 | **自定义天空偏好** | 用户可微调天空参数（云量/色温/粒子密度） | 设置面板提供滑块；修改后实时预览；偏好存入 IndexedDB |

## 6. 技术要点备忘

| 领域 | 关键决策 |
|------|----------|
| **音乐** | Web Audio API 合成，零外部依赖；AudioContext + OscillatorNode + 白噪声滤波；4 种 preset 对应天气；切换时 GainNode 交叉淡入淡出 |
| **通知** | Notification API + Dexie 存储提醒规则 + requestAnimationFrame 轮询检查（Service Worker 后续 P2 接入） |
| **重复事件** | 在 eventStore 中增加 `rrule` 字段（简化版 RRule 字符串）；展示层按规则展开虚拟实例 |
| **标签** | Dexie 新增 tags 表；events 表增加 tagIds 数组字段；多对多关系 |
| **搜索** | Dexie where().startsWith() 索引查询 + 内存模糊匹配混合策略 |
| **视觉增强** | 在 SkyRenderer 现有架构内增强：Perlin noise 函数注入云朵边缘；太阳添加径向渐变+光线；雨线段改斜线+alpha拖尾；雪花改六角形路径 |
| **视图统一** | SkyRenderer 抽取为独立渲染层组件（<SkyBackground>），三视图引入；内容区统一毛玻璃卡片 |
| **天气联动** | WeatherService 已获取 temperature/humidity/windSpeed，新增映射函数到 SkyRenderer 参数 |

## 7. 待确认问题

| # | 问题 | 影响 | 建议默认 |
|---|------|------|----------|
| Q1 | **通知授权时机**：应用启动时立即请求 Notification 权限，还是用户首次设置提醒时才请求？ | 过早请求可能被用户拒绝 | **首次设置提醒时请求**，并在 SkyView 显示"开启提醒"引导条 |
| Q2 | **重复事件编辑范围**：编辑重复事件时，默认影响"仅此一次"还是"全部实例"？ | 误操作风险 | **默认仅此一次**，弹窗提供"应用到全部"选项 |
| Q3 | **环境音效自动播放**：浏览器限制 AudioContext 必须由用户手势触发，是否需要用户手动点击才能开始播放？ | 首次体验 | **需要一次用户点击激活**（点击 🎵 或任意交互后记住偏好自动播放） |
| Q4 | **统计视图天空模式**：StatsView 背景强制使用夜空（配合数据主题），还是跟随当前天气？ | 视觉一致性 | **默认夜空**，提供切换按钮 |
| Q5 | **Dexie 数据库迁移**：新增 tags 表和 events 表字段变更需要版本升级，是否需要为已有用户做数据迁移？ | 数据安全 | **必须迁移**，Dexie version 升级 + 迁移函数，旧数据保留 |
