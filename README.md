# SkyDesk 2.0

极简智能提醒工具

## 简介

SkyDesk 是一个专注于提醒功能的极简 Web 应用。采用 Apple 设计风格，提供清晰、简洁的用户体验。

## 功能特性

- ✅ **快速添加提醒** - 支持自定义时间、优先级
- 🔔 **三重提醒方式** - 浏览器通知 + 页面横幅 + 声音提醒
- 📱 **响应式设计** - 完美适配桌面和移动设备
- 💾 **数据备份** - 支持 JSON 导出/导入
- 🎨 **Apple 极简风格** - 浅色主题、圆角设计、毛玻璃效果

## 技术栈

- Vue 3 + Vite
- IndexedDB (Dexie.js)
- Web Audio API
- Browser Notification API

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用说明

1. 打开应用后，允许浏览器通知权限以获得最佳体验
2. 在首页快速添加提醒
3. 提醒将在设定时间通过浏览器通知、页面横幅和声音提醒您
4. 在设置页面可以导出/导入数据备份

## 注意事项

- 请保持页面打开以接收提醒
- 浏览器关闭后无法触发提醒
- 建议定期导出数据备份
